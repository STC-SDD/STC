# Projet STC - Plateforme de sous-tritrage collaboratif

Bienvenue ! Ce projet vise à développer une plateforme où plusieurs utilisateurs collaborent pour sous-titrer une vidéo en direct.

## Fonctionnalités principales

- Gestion en temps réel des sous-titreurs
- Attribution dynamique des fragments vidéo
- Fusion et diffusion synchronisée des sous-titres

Voir la documentation pour plus de détails.
